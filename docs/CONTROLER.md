# Controler

## 概要

本アプリの操作を行うメインのコントローラーUIです。

構成は以下の通りとする。
1. 複数の Menu item から構成する。
2. Menu item は横一列に配置する。
3. アプリウインドウの下部中央に表示する。

## Menu item の種類

Menu item は以下二種類のUIから構成される。
- 円
- 正方形(角丸)

### 円

吹き出しを持つ UI です。

クリックすることで、吹き出しの表示/非表示をコントロールします。

### 正方形(角丸)

吹き出しを持たない UI です。

選択状態を持ち、クリックすることで選択状態になります。

### 吹き出し

円 UI をクリックすることで表示される UI です。

吹き出しの表示位置は、円UIのX軸の中心と吹き出しのX軸の中心を同じ位置になるように表示します。

## Menu item の構成

Menu item の構成は 左から、ログ照会、データ取得、ユーザー、歯車、+ (プラス)、ボード とする。

### ログ照会

(1) Menu item の種類
円

(2) メニューの概要
出力ログを照会する。

### データ取得

(1) Menu item の種類
円

(2) メニューの概要
ボードのデータ取得を行う

### ユーザー

(1) Menu item の種類
円

(2) メニューの概要
Slackアカウントの管理

### 歯車

(1) Menu item の種類
円

(2) メニューの概要
現在選択れているボードの設定、ボードの削除

### + (プラス)

(1) Menu item の種類
円

(2) メニューの概要
ボードの追加

### ボード

(1) Menu item の種類
正方形(角丸)

(2) メニューの概要
ボードの条件で slack チャンネル、メッセージを表示する。

## 実装の現状 (Tauri 版)

実装は `src/components/MainControllerView.tsx` にあります。
吹き出しは `BubbleButton` (`@floating-ui/react`) が表示します。
吹き出しは円 UI の中心に合わせて表示し、ウインドウの端からはみ出す場合は横にずらします。
ずらしても、矢印は円 UI を指します。
同時に開ける吹き出しは 1 つだけです。

実際の並びは、左から次のとおりです。
旧 WinUI 版の並びを引き継いでおり、上の「Menu item の構成」とは一部異なります。

| 順 | Menu item | 種類 | 内容 |
|----|-----------|------|------|
| 1 | ログ | 円 | 直近 500 行のログを表示する。「アプリ」(Tauri 側) と「サーバー」(`/api/logs`) を切り替えられる。更新、クリップボードへのコピーができる |
| 2 | ユーザー | 円 | プロフィール表示、サーバーの URL と最終同期時刻の表示、今すぐ全体を同期、接続の解除 (保存した URL と API キーを削除) |
| 3 | 歯車 | 円 | カスタムボードを表示している間だけ、名前とチャンネルの変更、ボードの削除ができる (削除は 2 回押して確定) |
| 4 | メッセージ | 円 | チャンネル名を指定してメッセージを投稿する |
| 5 | + (プラス) | 円 | カスタムボードの追加 (最大 10 件) |
| 6 | データ取得 | 正方形 | 表示中のボードのチャンネルを、サーバーに今すぐ同期させる。更新中 (同期の完了を待つ間、最長 60 秒) は赤く表示する |
| 7 | ① | 正方形 | 参加中のチャンネルだけを表示する |
| 8 | ② | 正方形 | 未参加のチャンネルだけを表示する |
| 9〜 | ボード | 正方形 | カスタムボードごとに 1 つ。名前の先頭 1 文字を表示し、名前は吹き出しのヒントに出す |

- ①、②、ボードは選択状態を持ち、選択中は赤く表示します。
- 選択中のものをもう一度押すと、選択を解除して全チャンネル (接頭辞が `times` などのチャンネル。接頭辞はサーバーの設定) の表示に戻ります。
- データ取得は、仕様では円ですが、吹き出しを持たないため正方形にしています。
